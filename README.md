# Legacy website

This public repository preserves the original GitHub Pages address. HTML pages redirect to https://cesare381.com; the six existing PDFs remain byte-identical snapshots from df7cf2b72a68f0adef3f79f0b719ba7c3d3757d4.

The current website is maintained separately in the private cesare381-mainpage repository. Do not copy current private development work into this repository.

Publish this branch directly from its root with GitHub Pages. The root .nojekyll file disables Jekyll processing. JavaScript redirects preserve query parameters and fragments. With JavaScript disabled, HTML refresh and a visible link still reach the corresponding page, but query preservation is not guaranteed. Unknown URLs remain genuine 404s.

To restore the former website, revert the migration commit with a normal Git commit; do not rewrite history.
